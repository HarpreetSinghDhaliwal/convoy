# ads

Phase 1 monetization: AdMob in the trip feed (not AdSense — that's web-only,
this is a native app). Phase 2, later: subscription tier (ad-free, higher
trip quota, priority placement, faster KYC) — not started until real usage
data justifies pricing it.

**Blueprint refs:** §09 monetization, §10 Phase 04.
**Depends on:** trips (feed placement).

**Planned exports:** `TripFeedAdSlot`, `useSubscriptionStatus()` (Phase 2, not yet).
